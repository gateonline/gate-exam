Test Instructions

  • The test contains 15 questions.
  • The total duration is 30 minutes.

Question Types

  • MCQ: Only one option can be selected.
  • MSQ: One or more options can be selected.
  • NAT: Enter the numerical answer using the input box.
  • For NAT questions, enter the answer correct to TWO decimal places.

Marking Scheme

NAT Correct: +2 Wrong: 0 Unanswered: 0
